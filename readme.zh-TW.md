# 網路拓樸與路由分析工具箱 (Network Topology & Route Analysis Toolkit)

> **切換語言：[English](readme.md) | [繁體中文]**

本工具專為網路工程師與 NOC 監控中心設計，能將底層網路設備（如 Juniper, Cisco, Fortinet）的文字數據轉化為直觀的互動式圖表與具備商業價值的管理資訊。

## 🚀 核心功能

### 1. 智慧拓樸視覺化 (Topology Visualization)
*   **多格式解析引擎**：支援解析 Juniper 的 OSPF 輸出、Fortinet/Cisco 的 OSPF 表，以及標準的 LLDP 鄰居表。
*   **自動設備識別**：內建正則表達式，可根據設備命名規則自動分類（如防火牆、交換器）並指派對應的 SVG 圖示。
*   **介面樣式映射**：自動偵測鏈路類型（如 10G 高速連線或 ae 聚合鏈路），並動態調整連線的粗細與顏色。

### 2. 遞迴路由分析引擎 (Route Analyzer)
*   **精準路由建模**：模擬路由器行為，利用 **最長匹配優先 (LPM)** 演算法在 CIDR 路由表中尋找精確條目。
*   **遞迴路徑追蹤**：從起點開始模擬封包跳轉，直到抵達目的地、發生環路 (Loop) 或遇到黑洞 (Blackhole)。
*   **支援等價多路徑 (ECMP)**：若存在多個下一跳 (Next-hop)，程式能同時記錄並顯示所有分支路徑。

### 3. VLAN 與資產稽核 (VLAN & Asset Audit)
*   **IP-MAC 深度關聯**：整合 ARP 表與連接埠資訊，解決「已知介面但未知設備身份」的痛點。
*   **OUI 製造商辨識**：透過 MAC 位址前 6 碼自動辨識網卡製造商（如 Apple, Cisco, VMware），協助判斷設備種類。
*   **自動化報表生成**：支援將巢狀數據平坦化，匯出美化後的 **Excel (XLSX)** 或 **CSV** 報表，並能自動調整欄位寬度。

## 🛠️ 運作原理

1.  **解析與規範化**：透過正則表達式提取網段、下一跳、介面等資訊，並自動將 MAC 位址格式規範化（過濾冒號或點並轉為大寫）。
2.  **物理佈局演算**：使用 **vis.js** 的 ForceAtlas2 演算法，透過斥力與彈簧力讓節點自動散開，避免重疊。提供靜態、階層與物理三種佈局模式。
3.  **狀態標記與渲染**：分析路徑後，會在拓樸圖上以動態流光高亮顯示，並在節點旁標註轉發封包的具體路由依據。
4.  **持久化管理**：利用 **localStorage** 記憶節點位置與設定，並設有 **8 小時自動過期機制**，兼顧效能與準確性。

## 💡 應用場景

*   **虛擬追蹤路徑 (Virtual Traceroute)**：在無法連線設備或 ICMP 被阻擋時，透過現有路由表離線預測封包路徑，診斷斷線點。
*   **網路安全稽核**：快速產出全網設備清冊，辨識不明 MAC 位址、私人接入設備或 VMware 虛擬化環境分布。
*   **異地備援 (DR) 演練**：修改路由權重或模擬節點失效，觀察流量是否正確切換至備援路徑。
*   **故障診斷與遷移**：利用 **VLAN 搜尋** 或 **雙擊擴散選取** 功能，快速定位特定 VLAN 經過的所有交換器，輔助遷移規劃。
*   **自動化架構圖生成**：將 `show lldp neighbors` 文字直接貼入即可生成物理連線圖，取代傳統人工繪製 Visio 的繁瑣步驟。

## 📊 技術規格
*   **核心引擎**：JavaScript, vis.js (ForceAtlas2 Layout)
*   **資料格式**：JSON, CIDR, Regex
*   **匯出支援**：PNG 圖檔、Excel (XLSX)、CSV
*   **相容廠商**：Juniper, Cisco, Fortinet 等主流網路設備
