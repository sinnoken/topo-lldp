How It Works

Data Parsing

  • • LLDP Auto-Conversion: Built-in convertLldpToJson parses raw text to extract interfaces and neighbor devices.
  • • Regex Classification: Uses GROUP_RULES to automatically categorize devices as Firewalls (FGT) or Switches.

Visual Rendering

  • • Physics Engine: ForceAtlas2 simulates repulsive forces to automatically spread nodes and prevent overlap.
  • • Style Definition: Automatically assigns colors and line widths based on connection types (10G/VLAN/OOB).

Use Cases

Rapid Topology Generation

Paste show lldp neighbors output to skip tedious manual drawing in Visio.

Fault & Impact Assessment

Search for a device and use "Double-click depth" to quickly view all affected downstream nodes.

Asset Inventory

Differentiate between high-speed links (10G/100G) and standard links (1G) using colors.

End-to-End Visualization

Integrate Server and Windows naming conventions for a complete map from network gear to endpoints.

💡 Tips for First-Time Users

• Drag to Adjust: Manual node positions are saved automatically.

• State Persistence: Layout positions are cached for 8 hours.

• Switch Layout: If it looks cluttered, click "Physics" to auto-distribute.

• Quick Multi-select: Hold CTRL to select multiple nodes simultaneously.
