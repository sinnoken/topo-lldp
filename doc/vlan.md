## ## 運作原理 (How It Works)

此工具透過多層次的資料對照（Mapping）與清理，將底層網路數據轉化為易讀的報告：

### 1. **多維度資料關聯 (Multi-source Mapping)**

程式的核心在於 `parseArpData` 方法，它能處理複雜的 JSON 格式：

* **MAC 規範化**：自動過濾 MAC 位址中的冒號 (`:`) 或點 (`.`) 並統一轉為大寫，建立一個全域的 `globalArpMap`。
* **IP-MAC 對照**：將 ARP 資訊（IP 與 MAC）與設備的連接埠資訊進行關聯，解決了「只知道哪台設備在哪個孔，卻不知道它是誰」的問題。

### 2. **OUI 製造商識別**

* 程式內建了 **OUI (Organizationally Unique Identifier) 查詢機制**。
* 透過 MAC 位址的前 6 碼，自動辨識網卡製造商（如 Apple, Cisco, VMware），幫助管理員快速判斷終端設備的種類（例如是手機、伺服器還是虛擬機）。

### 3. **動態視覺化頭像 (SVG Avatar Generation)**

* **自動生成圖示**：`_generateInitialAvatarSvgForVis` 方法會根據設備名稱自動計算 Hash 值，並分配顏色與縮寫字母。
* **縮寫辨識**：在視覺化拓樸中，設備不再只是單調的圓點，而是帶有識別文字（如 "SW" 代表 Switch）的圓形圖示。

### 4. **資料平坦化與匯出引擎**

* **資料清洗**：透過 `getFlattenedData` 將巢狀的 JSON 物件攤平成一維陣列。
* **多格式輸出**：支援 **CSV** 與 **Excel (XLSX)** 匯出。它甚至能精準設定 Excel 的欄位寬度（如設定 MAC 欄位較寬，VLAN 欄位較窄），生成可直接提交的稽核報表。

## ## 應用場景 (Use Cases)

### 1. **網路安全稽核 (Security Auditing)**

* **情境**：資安官需要知道內網中是否有未知的 MAC 位址，或是有無私人設備接入。
* **應用**：將全網交換器的 MAC Table 與 ARP Table 匯入 `vlan.js`，快速產出一份包含「製造商、IP、MAC、對接介面、VLAN ID」的清冊，輕鬆抓出不明來源的設備。

### 2. **虛擬化環境盤點 (VMware/Hyper-V Inventory)**

* **情境**：在混亂的二層網路（L2）中，很難區分哪些是實體伺服器，哪些是虛擬機。
* **應用**：利用 OUI 辨識功能，系統會自動標記出 "VMware, Inc." 或 "Microsoft" 的 MAC 位址，幫助管理員快速掌握虛擬化主機的分布位置。

### 3. **VLAN 搬遷與清理規劃**

* **情境**：公司要重劃 VLAN，需要知道特定的 VLAN（如 VLAN 10）目前到底承載了多少裝置。
* **應用**：使用 `VlanAuditor` 的過濾與匯出功能，一鍵產出特定 VLAN 的設備列表，避免在搬遷過程中漏掉任何重要伺服器。

### 4. **自動化報表產出 (Automated Reporting)**

* **情境**：每個月需要提交一次機房設備統計報告給主管。
* **應用**：前端開發者可整合此腳本，讓工程師只需把 `show mac-address-table` 的 JSON 貼上，就能直接下載美化過的 Excel 報表，取代傳統人工在 Excel 慢慢查找對照的繁瑣步驟。

## ### 總結

`vlan.js` 是一個強大的「**資料轉譯器**」，它將枯燥的網路底層數據，透過 **OUI 對照**與 **資料攤平技術**，轉化為具備商業價值的管理資訊。
