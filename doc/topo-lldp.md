## ## 如何運作 (How It Works)

該程式透過「解析、轉換、渲染」三個階段將純文字資料轉化為動態圖表：

### 1. **智慧型設備識別 (Smart Identification)**

程式碼內建了 `identifyDeviceCategory` 函式與 `CONFIG.GROUP_RULES` 正則表達式：

* **自動分類**：根據設備名稱（如 `FGT` 為防火牆、特定命名規則為交換器）自動指派設備類型。
* **樣式對照**：透過 `THEME` 設定，不同類型的設備會顯示不同的 SVG 圖示（如防火牆顯示綠色盾牌、交換器顯示黃色圖示）。

### 2. **LLDP/OSPF 文本解析引擎**

這是本程式的核心技術，`convertLldpToJson` 函式處理多樣化的設備日誌：

* **多格式相容**：支援解析 Juniper 的 OSPF 輸出、Fortinet/Cisco 的 OSPF 表以及標準的 LLDP 鄰居表。
* **正規化連線**：自動抓取本地介面 (Local Interface)、遠端介面 (Remote Port) 與對端設備名稱 (System Name)。
* **介面樣式映射**：透過 `PORT_STYLES` 偵測關鍵字（如 `ae` 代表聚合鏈路、`10G` 代表高速連線），並自動調整線條粗細與顏色。

### 3. **動態佈局與物理模擬**

使用 vis.js 的物理引擎進行空間演算：

* **ForceAtlas2 演算法**：透過排斥力 (`gravitationalConstant`) 與彈簧力 (`springLength`) 讓節點自動散開，避免重疊並呈現自然的網路分佈。
* **三種佈局模式**：
* **靜態 (Static)**：手動拖拽並固定位置。
* **階層 (Hierarchical)**：由上而下（Core > Dist > Acc）的樹狀結構。
* **物理 (Physics)**：自動計算最佳化空間位置。



### 4. **持久化與狀態管理**

* **本地儲存**：利用 `localStorage` 記憶使用者的節點位置與資料內容，確保重新整理頁面後設定不會遺失。
* **自動快取過期**：設有 8 小時的快取機制 (`STORAGE_EXPIRY_MS`)，兼顧效能與資料準確性。

## ## 應用場景 (Use Cases)

### 1. **數據中心網路自動化生成**

* **情境**：工程師從核心交換器下達 `show lldp neighbors` 命令。
* **應用**：將大量文字直接貼入編輯器，程式即刻生成整座機房的物理連線圖，省去手動畫 Visio 的時間。

### 2. **故障診斷與鏈路分析**

* **情境**：網路出現迴圈或斷線，需確認連線類型。
* **應用**：利用程式的 **VLAN 搜尋功能** 或 **雙擊擴散選取**，快速找出特定 VLAN 經過的所有交換器路徑，或確認連線是否為「聚合鏈路 (Aggregate)」。

### 3. **IT 資產盤點與遷移規劃**

* **情境**：需要對老舊環境進行遷移，但缺乏更新的架構圖。
* **應用**：透過解析 OSPF 鄰居表，自動勾勒出 L3 層級的路由拓樸，幫助架構師理解設備間的邏輯關係。

### 4. **監控中心 (NOC) 視覺化看板**

* **情境**：需要即時展示網路狀態。
* **應用**：利用其 **PNG 匯出功能** 與 **互動式高亮**（Hover 效果），可將生成的拓樸作為技術文件的素材，或整合至內部網管系統的 Web 介面中。
