# 專案：[topo-lldp]

## 1. 目標
Developed using Vis.js, this tool transforms complex network connection data (LLDP) into intuitive, interactive topology maps. 

## 2. 核心功能清單 (Features)
* Smart Topology Visualization。
* Recursive Route Analysis Engine。
* Asset & VLAN Auditing。

## 3. 技術棧與限制 (Constraints)
* 前端框架：Tailwind CSS + daisyui + vis.js
* 後端：目前沒有
* 限制：請勿使用任何額外的第三方 UI 函式庫（如 Material-UI）。
